สร้างและดูแลโครงการงบ

เลือกหัวข้อด้านล่างเพื่อดูหน้าจอจริงในแต่ละขั้นตอน — จากปุ่มสร้าง ไปจนถึงปรับวงเงิน

จัดการงบประมาณ

ตารางโครงการทั้งหมดที่ดูแลได้ พร้อมยอดจอง เบิก คงเหลือ และปุ่มจัดการ

หน้างบโครงการ

เจาะลึกหนึ่งงบด้วยแท็บตามประเภทข้อมูล

เปิดจากรายชื่อในเมนูซ้ายหรือการ์ดภาพรวม — ดูสรุปยอด รายการ วงเงิน สิทธิ์ และบันทึกตรวจสอบ

รายละเอียดงบประมาณ

แต่ละแท็บแสดงรายละเอียดแต่ละประเภทข้อมูล กดเพื่อสลับภาพประกอบ

บันทึกการใช้งบ

บันทึกการจองงบ และเบิกใช้

การจองกันวงเงินไว้ล่วงหน้า การเบิกใช้แล้วตัดยอดจริง — ถ้าผูกกับจอง ระบบจะไม่นับวงเงินซ้ำ

1 การจอง

ลดยอด “ใช้ได้อีก” ทันที แต่ยังไม่ใช่รายจ่ายจริง ต้องระบุเหตุผลและแนบไฟล์ได้

2 เบิกใช้แล้ว

เบิกตรงหรือเบิกจากรายการจอง — เมื่อเบิกครบ จองจะเป็นสถานะเบิกครบแล้ว

มุมมองข้ามโครงการ

รายการใช้งบ และประวัติการเปลี่ยนแปลง

ติดตามทุกการจอง–เบิกในที่เดียว และย้อนดู Audit เมื่อต้องการตรวจสอบ

เมนูรายการใช้งบ

รวมรายการจากงบที่คุณเข้าถึงได้ กรองตามประเภทหรือสถานะเพื่อหาเอกสารประกอบเร็วขึ้น

เมนูประวัติการเปลี่ยนแปลง

บันทึกใครทำอะไร เมื่อไหร่ พร้อมเหตุผลและไฟล์แนบ — ผู้ดูทั่วไปจะไม่เห็นเมนูนี้

หลังบ้านเพิ่มเติม

ประเภทงบ และผู้ใช้–สิทธิ์

ทะเบียนประเภท A–Z สำหรับสร้างงบ และจัดการบัญชีผู้ใช้ระดับระบบพร้อมสิทธิ์รายงบ

จัดการประเภทงบ

กดหัวข้อเพื่อสลับระหว่างรายการที่สร้างแล้ว กับฟอร์มเพิ่มประเภท

ผู้ใช้และสิทธิ์

ตั้งบทบาทระดับระบบ ดูตารางสิทธิ์รายงบ และมอบหมายผู้รับผิดชอบ / ผู้จัดการรายการ / ผู้ดู

Rules

กฎสั้น ๆ ที่ควรจำตอนใช้จริง

  1. เปลี่ยนข้อมูลสำคัญต้องมีเหตุผล และแนบไฟล์ได้ทุกครั้ง
  2. จำนวนที่ใช้ได้ต้องไม่เกินวงเงิน
  3. ห้ามทำรายการจนยอดใช้ได้อีกติดลบ
  4. สร้างงบได้เฉพาะประเภทที่สถานะใช้งาน
  5. งบ Close อ่านอย่างเดียว — ห้ามเพิ่ม/แก้รายการ
  6. New เปลี่ยนเป็น Process อัตโนมัติ เมื่อมีการจองหรือเบิก
  7. เบิกจากจองต้องไม่เกินยอดจองคงเหลือ
  8. ห้ามยกเลิกจองที่มีเบิกอ้างอิงค้าง
  9. เมนูซ้ายแสดงเฉพาะงบที่เข้าถึงได้
  10. งานผู้ดูแลเปิดจากบล็อกผู้ใช้ ไม่ปนกับเมนูดูข้อมูล

ตารางฟิลด์ข้อมูลทั้งระบบ

สรุปช่องที่ผู้ใช้กรอก/เลือกในแต่ละเมนู — หากเป็นตัวเลือก จะระบุรายการตัวเลือกไว้ในคอลัมน์ขวาสุด

เมนู ชื่อ field ข้อมูล ลักษณะข้อมูลที่กรอก ตัวเลือก (ถ้าเป็นการเลือก)
สร้าง / แก้ไขงบ ประเภทงบประมาณ เลือกจากทะเบียนประเภทที่สถานะใช้งาน รหัส A–Z ตามที่ตั้งใน “จัดการประเภท” เช่น A พัฒนาระบบ / ดิจิทัล, B บำรุงรักษา, C ฝึกอบรม, D สำรอง
สร้าง / แก้ไขงบ ปีงบประมาณ / ช่วงเวลา ข้อความอิสระ —
สร้าง / แก้ไขงบ ชื่อโครงการ ข้อความ บังคับ —
สร้าง / แก้ไขงบ คำอธิบาย ข้อความยาว (ไม่บังคับ) —
สร้าง / แก้ไขงบ ผู้รับผิดชอบ เลือกหลายอีเมล (อย่างน้อย 1) รายชื่อผู้ใช้ในระบบ / พิมพ์อีเมลโดเมนองค์กร
สร้าง / แก้ไขงบ ผู้จัดการรายการ เลือกหลายอีเมล (ไม่บังคับ) เช่นเดียวกับผู้รับผิดชอบ
สร้าง / แก้ไขงบ ผู้ดู (dashboard) เลือกหลายอีเมล (ไม่บังคับ) เช่นเดียวกับผู้รับผิดชอบ
สร้างงบ วงเงินงบประมาณ (บาท) ตัวเลขทศนิยม ≥ 0 บังคับ —
สร้างงบ จำนวนที่ใช้ได้ (บาท) ตัวเลข ≤ วงเงิน —
สร้างงบ รายละเอียด/ที่มาของงบ ข้อความเหตุผล บังคับ —
สร้างงบ เลขที่เอกสารอ้างอิง ข้อความ (ไม่บังคับ) —
แก้ไขงบ สถานะงบประมาณ เลือกค่าเดียว New · Process · Close
แก้ไขงบ เหตุผลการแก้ไข ข้อความ บังคับ —
ปรับวงเงิน วงเงินงบประมาณใหม่ ตัวเลข —
ปรับวงเงิน จำนวนที่ใช้ได้ใหม่ ตัวเลข ≤ วงเงินใหม่ —
ปรับวงเงิน วันที่มีผล วันที่ (date) —
ปรับวงเงิน เลขที่เอกสารอ้างอิง ข้อความ (ไม่บังคับ) —
ปรับวงเงิน รายละเอียดการเปลี่ยนแปลง ข้อความ บังคับ —
จอง / เบิก งบประมาณ / โครงการ เลือกงบที่จัดการได้ รายการงบตามสิทธิ์ของผู้ใช้
จอง / เบิก ประเภทรายการ สลับโหมดฟอร์ม การจอง (RESERVE) · เบิกใช้แล้ว (DISBURSE)
เบิกใช้แล้ว เบิกจากรายการจอง เลือกหรือเว้นว่าง (เบิกตรง) รายการจองที่ยัง ACTIVE ของงบนั้น
จอง / เบิก จำนวนเงิน (บาท) ตัวเลข > 0 บังคับ —
จอง / เบิก วันที่รายการ วันที่ —
จอง / เบิก ชื่อ/รายละเอียดรายการ ข้อความ บังคับ —
จอง / เบิก หมวด ข้อความอิสระ เช่น ครุภัณฑ์ / จ้างเหมา / เดินทาง
จอง / เบิก คู่ค้า / ผู้รับเงิน ข้อความ —
จอง / เบิก เลขที่รายการ ข้อความ หรือเว้นว่างให้ระบบสร้าง —
จอง / เบิก หมายเหตุเพิ่มเติม ข้อความยาว —
จอง / เบิก / แก้งบ ไฟล์แนบ อัปโหลดหลายไฟล์ PDF, รูป, Excel, Word · ≤ 10 MB/ไฟล์ · สูงสุด 5 ไฟล์/ครั้ง
แก้ไข / ยกเลิกรายการ เหตุผล ข้อความ บังคับ —
ย้ายรายการ (ผู้ดูแล) งบปลายทาง เลือกงบอื่น งบที่ยังไม่ปิดและไม่ใช่งบต้นทาง
